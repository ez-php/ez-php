# Upgrading seeders: `SeederInterface::run(DatabaseInterface $db)`

**Breaking change.** `EzPhp\Migration\SeederInterface::run()` now takes the
`EzPhp\Contracts\DatabaseInterface` contract instead of the concrete
`EzPhp\Database\Database` class.

PHP does not allow an implementation to narrow a parameter type, so a seeder that still
declares `run(Database $db)` no longer satisfies the interface: loading it fails with a
fatal "Declaration … must be compatible with" error when `ez db:seed`, `ez db:setup` or
`ez migrate:fresh --seed` runs.

## What to change

In every file under `database/seeders/`:

```php
// before
use EzPhp\Database\Database;
use EzPhp\Migration\SeederInterface;

return new class implements SeederInterface {
    public function run(Database $db): void { /* ... */ }
};

// after
use EzPhp\Contracts\DatabaseInterface;
use EzPhp\Migration\SeederInterface;

return new class implements SeederInterface {
    public function run(DatabaseInterface $db): void { /* ... */ }
};
```

The interface offers `query()`, `execute()`, `transaction()` and `getPdo()` — everything a
seeder normally uses. The object passed in is still the framework's `Database`, so a seeder
that needs something beyond the contract can check `$db instanceof Database`.

New seeders generated by `ez make:seeder` already use the new signature.
